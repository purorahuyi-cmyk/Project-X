# Project-X
DVF Pro Elite X V4 - Advanced PineScript trading strategy with multi-timeframe volume confluence, futures-spot correlation, and smart trend engine
Philosophy

DVF Pro Elite X is built around confluence rather than a single signal. Instead of relying on one indicator, it combines volatility, trend, price location, momentum, volume, and candle behavior into a single visual framework.

Important Disclaimer

DVF Pro Elite X is an analytical tool, not a guaranteed trading system. Its signals and scores are rule-based calculations and should not be interpreted as predictions or guarantees of profitability.

Always evaluate the indicator through appropriate backtesting, forward testing, risk management, and market-specific validation before using it with real capital
